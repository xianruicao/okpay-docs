# OKPay.ai 用户手册

OKPay.ai 是一个虚拟卡平台。用户可以通过 USDT / USDC 充值账户余额，一键签发虚拟卡，用于线上消费、订阅付款等场景。

**使用流程：** 注册账户 → 充值余额（USDT / USDC）→ 签发虚拟卡 → 线上消费与查账。
