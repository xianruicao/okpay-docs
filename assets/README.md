# 素材目录（assets）

本目录用于存放 README 与文档中引用的图片素材，图片放在 `images/` 下。

## 当前截图

| 文件 | 页面 |
| --- | --- |
| `images/wallet.png` | 钱包 · 余额与资金明细 |
| `images/my-cards.png` | 我的卡 · 虚拟卡列表 |
| `images/card-detail.png` | 卡详情 · 卡片信息与额度 |

以上截图均已脱敏。

## 脱敏要求

新增或替换截图前，请确认画面中**不包含**以下任何真实敏感信息：

- 完整卡号、有效期、安全码（CVV）
- 真实邮箱、手机号等个人身份信息
- 钱包私钥、助记词、充值地址
- API Key 或其他凭证
- 真实客户信息

## 命名与引用

- 使用清晰的文件名，例如：`wallet.png`、`my-cards.png`、`card-detail.png`。
- 在 README 中使用相对路径引用，例如：`![钱包](assets/images/wallet.png)`。
