# 简介

## OKPay.ai 是什么

**OKPay.ai** 是一个**虚拟卡（Virtual Cards）平台**。你先把资金充值到平台钱包，再用余额一键签发虚拟卡，用于线上消费、订阅付款等场景。所有卡片、余额和每一笔交易都集中在一个界面里，一眼看清。

> 官网定位：**「卡片、余额、每一笔交易——一眼看清」**

## 核心能力

- **集中管理卡片** —— 所有虚拟卡集中在「我的卡」，随用随发。
- **可信的余额** —— 可用余额基于已核验的账户资金活动计算，确认到账后才更新。
- **清晰的流水** —— 钱包资金明细与卡片活动逐笔可查，支持导出 CSV。
- **中英双语** —— 界面支持中文 / 英文切换，并提供浅色 / 深色模式。
- **敏感信息打码** —— 卡号、有效期、安全码（CVV）默认打码显示，仅在需要时查看。

## 适用人群

- 需要为线上消费、订阅、投放等场景**快速开卡**的个人用户。
- 希望把多张虚拟卡的**余额与消费透明地集中管理**的用户。

## 主要功能一览

| 页面 | 作用 |
| --- | --- |
| **首页** | 查看可用余额、账户资金合计，快速进入充值 |
| **钱包** | 查看余额构成（各类资金状态）与资金明细流水 |
| **我的卡** | 申请并签发虚拟卡 |
| **卡片活动** | 查看卡片资金活动、导出 CSV |

## 名词解释

| 术语 | 含义 |
| --- | --- |
| 可用余额 | 已核验、当前可用于发卡消费的余额 |
| 虚拟卡 | 平台签发的线上支付卡，含卡号、有效期、安全码 |
| 临时卡 / 长期卡 | 卡片期限类型，见 [申请与签发虚拟卡](05-申请与签发虚拟卡.md) |
| 消费限额 | 单张卡可消费的额度上限 |
| 开卡费 | 每次发卡收取的固定费用 |
