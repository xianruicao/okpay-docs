# 快速开始

从零到用上第一张虚拟卡，只需四步。

## 四步上手

### 1️⃣ 注册账户
用邮箱创建账户并登录。详见 [账户注册与登录](02-账户注册与登录.md)。

### 2️⃣ 充值到钱包
向平台钱包充值资金。**发卡至少需要可用余额 USD 5.00**，充值到账并核验后，余额才会更新。详见 [充值到账](03-充值到账.md)。

### 3️⃣ 签发虚拟卡
进入「我的卡」，选择**消费限额**和**卡片期限**（临时卡 / 长期卡），确认费用后点击**立即发卡**。发卡成功后即可查看卡号、有效期与安全码。详见 [申请与签发虚拟卡](05-申请与签发虚拟卡.md)。

### 4️⃣ 使用与查账
拿卡号在线上消费；在「钱包」查看资金明细，在「卡片活动」查看每笔卡片交易并可导出 CSV。

## 小贴士

- 首次发卡前请确认可用余额 ≥ **USD 5.00**，否则「立即发卡」按钮不可用，需先「去充值」。
- 每次发卡除消费限额外，还会收取**开卡费 USD 1.00**。
- 顶部可切换**语言（中/英）**与**浅色/深色模式**。
