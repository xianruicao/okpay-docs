# 账户注册与登录

## 注册账户

1. 打开登录页，点击 **「创建账户」**。
2. 使用**邮箱**注册。
3. 按提示完成邮箱验证。 <!-- ⏳ 待补充：验证码/邮件链接的具体流程，以实际界面为准 -->
4. 设置登录密码，完成注册。

> OKPay.ai 采用**邮箱注册**，登录会话仅与你本人已核验的账户绑定。

## 登录

在登录页填写：

| 字段 | 说明 |
| --- | --- |
| **邮箱** | 注册时使用的邮箱，如 `you@example.com` |
| **密码** | 账户登录密码 |

填写后点击 **「登录」** 即可进入，登录后进入 [首页](../README.md)。可在任意设备（手机 / 电脑）登录，界面保持一致。

## 忘记密码 / 重置密码

1. 在登录页点击 **「忘记密码」**。
2. 进入「重置密码」页，填写注册**邮箱**。
3. 点击 **「发送重置链接」**，系统会向该邮箱发送一次性密码重置链接。
4. 打开邮件中的链接，按提示设置新密码即可。
5. 如需返回，可点击 **「返回登录」**。

## 实名认证（KYC）

OKPay.ai **无需 KYC 实名认证**，使用邮箱注册即可开始使用。
