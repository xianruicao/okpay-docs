# 充值到账

发卡与消费都依赖钱包里的**可用余额**，因此使用前需先充值。

## 币种说明

- 账户余额以 **USD** 显示。
- 充值通过 **USDT / USDC 等稳定币**完成，稳定币与美元约按 **1:1** 计。

## 如何充值

1. 在**首页**或**钱包**页点击 **「查看充值 / 去充值」** 按钮，进入充值流程。
2. 在 **「选择充值网络」** 下拉框中选择你要使用的区块链网络与币种。
3. 按页面显示的**收款地址 / 二维码**，从你的钱包转入对应的稳定币。
4. 转账上链并经平台确认后，资金到账并计入可用余额。

### 支持的充值网络

| 网络 | 支持币种 |
| --- | --- |
| **Ethereum (ETH)** | USDT / USDC |
| **Polygon** | USDT |
| **Base** | USDC |
| **Arbitrum** | USDT0 / USDC |
| **Tron (TRC20)** | USDT |

> ⚠️ **务必选对网络与币种**：转账时链和币种要与页面选择一致，否则可能导致资金丢失且无法找回。

## 到账与核验

> **重要：** 可用余额按**已完成、已核验**的账户资金活动计算。充值提交后，需等待平台确认到账，**可用余额才会更新**。

- 处理中的资金会在钱包的对应状态里单独展示（如「卡片操作处理中」「待退回钱包」等），直至状态确认。详见 [钱包与资金明细](04-钱包与资金明细.md)。

## 发卡最低余额

签发虚拟卡要求**可用余额至少 USD 5.00**。若余额不足，发卡页会提示「请先充值，直至已核验的可用余额达到 USD 5.00」。

## 充值费率

充值会按金额和你的会员等级收取一定费率，金额越大、等级越高，费率越低。详见 [费率与会员等级](08-费率与会员等级.md)。

## 常见问题

- **充值了为什么余额没变？** 稳定币需转账上链并经平台确认后才计入可用余额，请稍候或查看资金明细状态。
- **转错网络了怎么办？** 请务必按页面选择的网络与币种转账；转错链或转错币种可能无法找回。
