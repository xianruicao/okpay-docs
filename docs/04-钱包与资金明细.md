# 钱包与资金明细

「钱包」页展示你的**可用余额**、余额的各项构成，以及资金变动流水。

## 可用余额

页面顶部大字显示当前**可用余额**（USD），并标注「账户余额已核验」。这是当前可用于发卡消费的金额。

## 余额构成

余额按状态拆分为以下几项，帮助你了解资金去向：

| 项目 | 含义 |
| --- | --- |
| **卡片操作处理中** | 正在处理的发卡 / 卡片操作占用的资金 |
| **卡内资金** | 已加载到虚拟卡上的资金 |
| **授权占用** | 交易授权中被临时冻结的金额 |
| **待退回钱包** | 即将退回钱包但尚未到账的金额 |
| **待偿金额** | 待偿还 / 待结算的金额 |
| **会员合格充值累计** | 计入会员资格的累计合格充值 |
| **账户资金合计** | 上述各项汇总后的账户资金总额 |

> 💡 提示：可用余额按**已完成**的账户资金活动计算；卡片操作处理中、卡内资金、待退回金额与待偿金额会**分别展示**，直至对应状态确认。

## 资金明细

页面右侧「资金明细」列出**已完成的平台入金和平台出金**，分页展示（可翻页）。若暂无记录，会显示「暂无活动记录」。

- 资金明细 = 钱包层面的入金 / 出金；
- 单张卡的消费流水请看 [卡片活动与流水](07-卡片活动与流水.md)。
