# 管理我的卡

在「我的卡」页可查看和管理已签发的虚拟卡。

## 查看卡片信息

- 发卡成功后，可在卡片页面查看**卡号、有效期、安全码（CVV）**。
- 敏感信息默认打码，按需展开查看。

## 卡片状态与资金

- 卡上加载的资金显示为**卡内资金**；
- 卡片操作（发卡等）处理期间，相关金额计入**卡片操作处理中**；
- 退回钱包的金额在到账前显示为**待退回钱包**。

详见 [钱包与资金明细](04-钱包与资金明细.md)。
