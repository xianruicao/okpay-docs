# 管理我的卡

在「我的卡」中点击任意一张卡，进入 **「卡详情」** 页，可查看卡片信息、额度使用情况，并进行冻结、取消等操作。

## 卡片信息

- 卡详情页顶部展示卡面：卡片类型（如「虚拟卡 · 临时」）、状态（如 **正常**）以及卡号后四位（其余默认打码）。
- 点击 **「显示卡片信息」**，可查看完整的**卡号、有效期、安全码（CVV）**。
  > ⚠️ 卡号、有效期和安全码**只显示一次，随后会自动隐藏**，请及时记录。

## 最新用卡验证（验证码）

- 部分交易可能需要输入一次性验证码（如 3DS / OTP 验证）。
- 需要验证码时，会在「最新用卡验证 · 验证码」区块显示；若近期没有相关活动，则显示「无需验证码」。

## 卡片额度

「卡片额度」区块展示这张卡的资金使用情况（状态标记为「已同步」）：

| 项目 | 含义 |
| --- | --- |
| **消费限额** | 这张卡的额度上限 |
| **可用预留** | 当前仍可使用的额度 |
| **授权占用** | 交易授权中被临时占用的金额 |
| **已结算消费** | 已完成结算的消费金额 |
| **已用额度** | 已使用额度的百分比 |

## 卡片管理

在「卡片管理」区块可对卡片进行操作：**可临时冻结、恢复使用，或永久取消卡片。**

| 操作 | 说明 |
| --- | --- |
| **冻结卡片** | 临时冻结，卡片暂停使用，之后可恢复 |
| **取消卡片** | ⚠️ **永久取消**卡片，不可恢复 |

> 取消卡片时，卡上剩余的可用预留将退回钱包，并按退款金额收取退款手续费（费率随会员等级不同，详见 [费率与会员等级](08-费率与会员等级.md)）。

## 卡片活动

卡详情页右侧会列出**这张卡**的资金活动，可导出 CSV。全部卡片的活动汇总见 [卡片活动与流水](07-卡片活动与流水.md)。
