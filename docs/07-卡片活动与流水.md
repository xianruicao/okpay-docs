# 卡片活动与流水

「卡片活动」页展示卡片相关的资金活动记录。

## 查看卡片活动

- 页面列出**卡片资金活动**，分页展示（可翻页）。
- 若暂无记录，会显示「暂无卡片活动 —— 卡片资金活动会显示在这里」。

## 导出 CSV

点击右上角 **「导出 CSV」**，可将卡片活动导出为 CSV 文件，便于对账或存档。

## 与钱包资金明细的区别

| 页面 | 记录内容 |
| --- | --- |
| **卡片活动** | 卡片层面的资金活动（消费、退款等） |
| **钱包 · 资金明细** | 钱包层面的平台入金 / 出金 |

对账时可两处结合查看。
