# 费用与限额说明

> 以下费率与限额来自产品界面展示，**最终以发卡时生效的费率为准**。

## 费用

| 项目 | 费用 | 说明 |
| --- | --- | --- |
| **开卡费** | USD 1.00 / 张 | 每次签发虚拟卡收取 |
| **退款手续费** | 退款金额的 **6.00%** | 退款时按比例收取 |
| 充值手续费 | <!-- ⏳ 待补充 --> | 以充值页面为准 |

**发卡所需余额** = 消费限额 + 开卡费。
例：消费限额 USD 100.00 + 开卡费 USD 1.00 = **所需余额 USD 101.00**。

## 限额

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| **发卡最低可用余额** | USD 5.00 | 低于此值无法发卡 |
| **消费限额输入** | 正数 USD，最多两位小数 | 预设快捷值：10 / 25 / 50 / 100 |
| 单账户发卡数量上限 | <!-- ⏳ 待补充 --> | 以实际界面为准 |
| 单卡 / 单笔消费上限 | <!-- ⏳ 待补充 --> | 以实际界面为准 |
