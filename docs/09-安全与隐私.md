# 安全与隐私

OKPay.ai 在设计上强调账户安全与信息保护。

## 敏感信息打码

- 卡号、有效期、安全码（CVV）等敏感信息**默认打码显示**，不会完整暴露，仅在需要时查看。

## 账户与数据

- **登录会话仅与你本人绑定**，每次登录都对已注册、已核验的账户进行身份验证。
- 你的数据只属于你自己。

## 余额可信

- 可用余额只在**确认到账、完成核验后**才更新，展示的余额真实可信。

## 账户安全建议

- 使用高强度、独立的登录密码，妥善保管邮箱。
- 不要向他人透露卡号、有效期与安全码。
- 发现异常交易或账户风险，及时 [联系我们](11-联系我们.md)。
